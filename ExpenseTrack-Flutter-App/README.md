# ExpenseTrack – Advanced Flutter Personal Finance App

ExpenseTrack is a high-performance, offline-first cross-platform mobile application built with Flutter, Dart, SQLite, and Riverpod. It enables users to track income and expenses, monitor category-wise spending via interactive charts, manage monthly budgets, and export financial reports.

## Features
- **Offline-First SQLite Database**: Secure local storage for all financial transactions and budgets.
- **Financial Dashboard**: Real-time calculation of total income, expenses, and net account balance.
- **Interactive Charts**: Powered by `fl_chart` for visual category-wise spending breakdowns.
- **Budget Management**: Set monthly limits per category with visual progress bars.
- **CSV Data Export**: Export transaction history for offline analysis.

## Tech Stack
- **Framework**: Flutter 3.x, Dart 3.x, Material Design 3
- **Database**: SQLite (`sqflite`)
- **State Management**: Flutter Riverpod

## Getting Started
1. Ensure Flutter SDK is installed.
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the application:
   ```bash
   flutter run
   ```
